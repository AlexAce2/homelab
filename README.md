Homelab

A budget-built home lab for learning networking, virtualization, and security hands-on. I'm building it while studying for my CCNA and working toward associate degrees in Network Specialist and Cybersecurity Specialist.

The lab is fully separate from my family's network. One cable connects it to the upstream network, and everything else sits behind my own firewall.

Goals
Practice VLANs, trunking, routing, and firewall rules on real hardware (CCNA skills)
Run virtual machines on Proxmox: pfSense firewall, Linux servers, Windows Server with Active Directory
Build a NAS I can reach securely from outside the house (VPN, no open ports)
Practice defensive security: logging, monitoring, and isolated attack/defend exercises
Document everything, including mistakes, so the work is reproducible
